# Frontend Practice Lab

This repository collects all the projects I’ve built while following [The Odin Project](https://www.theodinproject.com/) curriculum.  
Each folder contains a self-contained project with its own setup, code, and (where relevant) a live demo build.

## 🛠 Tech Stack (varies per project)
- Vanilla JS (modules), HTML5, CSS3
- Webpack + Babel (where applicable)
- ESLint + Prettier configs
- Jest (in TDD and game logic tests)
